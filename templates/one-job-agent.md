# One-job agent

Copy this file into your own repo as `AGENT.md`. Fill the blanks. Do not add a second job.

An agent judges. It reads the situation, chooses from the options below, and can choose to do nothing. A job that takes the same action every time is a workflow, not an agent.

## The blanks

1. **The job, in one sentence.**
2. **The trigger.** What starts it while you are not at the keyboard. The trigger only wakes it.
3. **The options.** What it is allowed to choose between. One of them is doing nothing.
4. **The boundary.** What it may read. What it must never do.
5. **What finished looks like,** including the written reason for its choice.
6. **Where the result goes,** so you can open it afterward.

## The test

Answer each one yes or no, with one line of proof. All five must be yes.

1. It has one named job, not a list of things it can do.
2. Something starts it while you are away. If you have to open it and type, it is a workflow.
3. Its boundary is written down.
4. It chose. Faced with a real case, it picked one option, or correctly picked none, and wrote the reason.
5. The output and the reason were waiting somewhere you could open afterward.

A "no" on any line means this is not an agent yet. Bring that answer anyway.

## Hard limits

It does not send email, post to chat, publish, or spend money. It does not change a live client account. Drafts only.
