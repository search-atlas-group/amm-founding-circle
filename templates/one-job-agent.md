# One-job agent

Copy this file into your own repo as `AGENT.md`. Fill the five blanks. Do not add a second job.

## The five blanks

1. **The job, in one sentence.**
2. **The trigger.** What starts it while you are not at the keyboard.
3. **The boundary.** What it may read. What it must never do.
4. **What finished looks like.**
5. **Where the result goes,** so you can open it afterward.

## The test

Answer each one yes or no, with one line of proof. All five must be yes.

1. It has one named job, not a list of things it can do.
2. Something starts it while you are away. If you have to open it and type, it is a workflow.
3. Its boundary is written down.
4. It finished the deliverable once without you stepping in mid-run.
5. The output was waiting somewhere you could open afterward.

A "no" on any line means this is not an agent yet. Bring that answer anyway.

## Hard limits

It does not send email, post to chat, publish, or spend money. It does not change a live client account. Drafts only.
