## Before first use

1. Confirm the foundation revision and shared file path supplied by the owner. In a fresh session, ask the assistant to name the approved pilot task, cite that path/revision, and state one boundary. Compare the answer with the checked-out file or owner-provided reference.
2. If the assistant cannot cite the reviewed baseline, names an unapproved source, or claims it changed something, stop and contact the owner. This check proves knowledge loading only; it does not prove live connector or account access.

## Use it
1. Sign in as yourself. Accept your own invitation or complete your own platform login. Never borrow the owner's credentials, cookies, keys or phone session.
2. Ask one question per thread. Name the approved project/source and requested time period.
3. Example: “Summarize the approved status page for this project. Cite the source and its update date. Do not change anything.”
4. Check the source before relying on the answer. If the assistant cannot access it, ask the owner; do not send credentials or another client's data to work around the denial.
5. Do not upload confidential content, private DMs, transcripts, personal information or data outside this card's audience. Channel replies are visible to that channel. Do not assume a DM makes shared bot memory private.
6. A write/send/publish request goes to the human owner as a draft; this pilot does not execute it. Approval for one action is not blanket permission for future actions.
7. If an answer shows the wrong project, unexpected private context, or claims an unrequested change: stop, contact the owner privately and preserve only the minimum incident reference. Do not forward or repeat the exposed content.

## What you have not received

You have access to this surface and task, not the owner's whole system. Shared skills are procedures, not credentials. A Search Atlas seat is not proof that Borg shares owner chats, files or running agents. Coworker is Search Atlas's agent, not an arbitrary Hermes runtime.

On departure, owner revokes all access and checks a fresh request is denied. Your logout alone may not remove shared grants.
