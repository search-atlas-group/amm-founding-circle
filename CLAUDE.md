# Claude instructions

Use the shared, CLI-neutral rules in [`AGENTS.md`](AGENTS.md). The Founding
Circle is the canonical source for skills, artifacts, tools, SHEP, and
onboarding; do not look for or recreate a sibling `amm-toolkit`.

Path defaults are `AMM_MOTHERSHIP_ROOT=~/amm-mothership`, with
`founding-circle/`, `work/`, and `archive/` beneath it. Respect
`AMM_FOUNDING_CIRCLE_DIR`, `AMM_WORK_DIR`, and `AMM_ARCHIVE_DIR` when set.
Keep member files in `work/`, preserve local changes, and use the platform
migration script in dry-run mode before applying changes.
