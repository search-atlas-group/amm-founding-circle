AI operations / baseline 01

Make the agent
legible.

The safest agent is not the one with the best promise. It is the one whose reach, actions, and evidence we can see.

The operating question
What can this agent touch — and can we prove it?Use this baseline across Hermes, Claude Code, Gemini, Cursor, Codex, and Board.

Four controls before scale

owner → evidence → review
01 / INVENTORY

Know what runs.

Skills, tools, models, connectors, credentials, browser sessions, and memory stores. Unknown is an unreviewed dependency.

02 / CAPABILITY

Limit the reach.

Default-deny access to files, shell, network, browser, and external systems. Grant only what the job needs.

03 / EVIDENCE

Keep the trail.

Record approvals, tool calls, secret leases, routing decisions, memory changes, and the evidence behind every exception.

04 / RESPONSE

Stop it fast.

Test prompt injection, malicious updates, and credential exposure. Keep a kill switch and practise revocation.

THIS WEEK / Start with one inventory and one permission gap. Policy is the starting line; evidence is the finish.
