Hand one deliverable to your agent.

Use the agent you already run. If you don't have one, the test below tells you whether what you build is one.

An agent is
a standing worker with one named job, that starts while you are not at the keyboard, inside a boundary you wrote down.
It is not
a prompt you paste in, a workflow you click run on, or a chat you have to sit and watch.

The test. All five, or it isn't an agent.

  1. One named job, not a list of things it can do.
  2. Something starts it while you are away. If you have to open it and type, it is a workflow.
  3. Its boundary is written down: what it may read, what it must never do.
  4. It finished the deliverable once, without you stepping in mid-run.
  5. The output was waiting somewhere you could open afterward. Not only inside a chat you watched.
