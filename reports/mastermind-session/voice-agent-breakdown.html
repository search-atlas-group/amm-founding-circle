01 / the loop
A VOICE AGENT IS NOT A RECORDING

A conversation is a loop.

Audio enters. The system understands the turn, chooses whether to use a tool, and speaks back—until the person interrupts or redirects it.

Speak

Microphone input arrives as a stream, not a finished file.

Understand

Words, pauses, interruptions, and turn boundaries become signal.

Act carefully

Answer or call one approved source; verify before claiming success.

Speak back

Stream the answer, stay interruptible, and retain a visible trace.

ADD CAPABILITY BEFORE AUTHORITY

Build one useful
conversation first.

Start with a read-only test session. Add turn-taking, one tool, transcript visibility, and guardrails before any write action.

Greeting → streaming audio

Say hello immediately; listen and speak in small chunks.

fast feedback

Turn-taking → one tool call

Handle pauses and interruptions; fetch a test session's status.

read-only first

Backchannel → transcript

Use “let me check” while looking up; save what was said and done.

visible evidence

Guardrails → measure

Restrict access; test speed, accuracy, interruptions, and failures.

stop before writes
