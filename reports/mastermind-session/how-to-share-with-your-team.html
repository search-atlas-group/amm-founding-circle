PERSONAL CONTACT

Make the shared bot
a separate profile.

Set up the surface

One profile, one identity

  1. Create a dedicated Hermes profile for the bot.
  2. Put the bot persona and team-safe skills there.
  3. Connect BlueBubbles, WhatsApp, Telegram, Discord, or Slack.
  4. Pair members or use an explicit allowlist.
Keep the boundary visible

Start read-only

  • Use research tools first; no terminal or state-changing tools.
  • Separate the bot's memory and credentials from JD's profile.
  • Provide a human fallback and a clear stop path.
  • Do not imply that messaging shares the owner's local system.
Pilot: one member asks for a read-only status lookup. The agent returns the answer and a visible transcript. A write request is blocked or routed to a human.

TEST THE HANDOFF

Share one useful
conversation, then measure it.

“What is happening in the active session?”
That is enough for version one.

One owner

Names the system, source, and member-facing boundary.

Two or three teammates

Use their own identities. No credential sharing.

One read-only task

Correct answer, visible source, transcript, or thread.

One stop test

Interrupt, request a write, and prove the guardrail.

After the pilot: keep the conversational surface, add a structured board, or build a deeper shared runtime. Do not reverse that order.
