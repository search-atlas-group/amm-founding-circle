03 / Decision rules

Score first, test second, share last.

The report separates usefulness from transfer safety so a promising idea does not skip the adaptation step.

Read the bars

Compare the profile

Need fit, practical value, transfer precision, and evidence confidence all use the same scale. A high need score with low precision belongs in adaptation.

Validate the edge

Test a real member task

Use one realistic task and one negative or security case. Record completion, time, correction count, confidence, and business relevance.

Protect the boundary

Sanitize before migration

Remove private infrastructure, credentials, Search Atlas assumptions, and internal workflows before any approved skill enters AMM.

Keep this gate explicit.
  • No skill transfer, repository upload, or external message is authorized by this report.
  • Scores should be updated from observed member evidence, not enthusiasm alone.
  • Member names and sensitive session details are summarized rather than reproduced.
