# Observe. Specify. Build. Verify.

Prepared companion for the November 12, 2026 mastermind. These are pre-session teaching materials, not a transcript or replay.

**The idea:** separate what an agent may inspect, what it is asked to build, and what evidence allows its work to advance.

## Use with your agent

- [Reusable skill](../../skills/observe-specify-build-verify/SKILL.md)
- [Runnable example and tests](../../examples/observe-specify-build-verify/README.md)

From your existing Founding Circle clone, run `git pull --ff-only`. If Git refuses because of local changes or divergence, stop and preserve those changes; do not reset or force-update. Then follow the example's platform-specific commands. No Craft Anything install, paid tool, private account or third-party target is needed for the companion fixture.

Keep client/member input and run output in your private `work/` location, outside the tracked shared repository. A passing fixture is not permission to publish or a claim that browser behavior or an autonomous agent was tested.

## Sources and distinctions

[Craft Anything](https://github.com/storytold/craft-anything) documents Study -> Build -> Check -> Ready. It is an early-alpha app/CLI/MCP project, not the skill provided here. Its [permission documentation](https://github.com/storytold/craft-anything/blob/main/docs/claude-code.md) explains backend-specific limits.

Clean-room information boundaries and independent QA protect different things. Neither a mode name nor a role prompt guarantees legal clearance or operating-system isolation. Use owned or explicitly permitted targets; do not copy protected assets or bypass access controls.
